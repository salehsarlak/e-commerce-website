### 🌟 Features

- 🏠 **Modern Hero Section** with attractive furniture showcase
- 🛒 **Product Catalog** with 8+ stylish furniture cards
- 🎨 Color variants for each product
- 📝 **Blog Section** with latest furniture trends
- 📊 Customer success stories & statistics
- 📱 Fully **Responsive** (Mobile + Tablet + Desktop)
- ⚡ Pure HTML & CSS (no JavaScript frameworks)
- 🎭 Beautiful animations & hover effects
- 📰 Newsletter subscription form
- 🔗 Social media integration

### 📂 Project Structure

```bash
modern-furniture-store-website/
├── assets/
│   └── images/
│       ├── products/     # Product images
│       ├── posts/        # Blog post images
│       └── ...           # Other assets
├── css/
│   ├── reset.css         # CSS reset
│   └── style.css         # Main styles
├── index.html            # Main page
├── screenshot.png        # Preview image
└── README.md
```

---

### 🚀 How to Run Locally

1. Clone the repository:
```bash
git clone https://github.com/salehsarlak/modern-furniture-store-website.git
```

2. Open `index.html` in your browser.

That's it! No build step required.
